Proyectos

Plantilla de GitHub

ai-agents-template

Una plantilla reutilizable para trabajar con agentes en la nube en Cursor y GitHub Copilot.

Da a los agentes las instrucciones y las herramientas para configurar por su cuenta el entorno de desarrollo de un proyecto desde cero.

Ver en GitHub

Cómo funciona

  1. Plantilla: Creas tu repositorio a partir de la plantilla.
  2. Reglas comunes: Un único archivo de reglas para los agentes.
  3. Skills: Instrucciones reutilizables para las tareas habituales.
  4. Configuración autónoma: Un agente explora el proyecto y prepara su entorno desde cero.
  5. Entorno listo: Cursor y GitHub Copilot arrancan con el entorno preparado, y CI revisa las skills en cada pull request.
